slaptain

A Kubernetes operator for a multi-site, multi-master replicating OpenLDAP cluster.

slaptain manages the lifecycle of an OpenLDAP cluster on Kubernetes: cluster bootstrap, N-way multi-master replication within a site and between sites, databases, schemas and ACLs as custom resources, backup and restore.

Source and documentation github.com/chuck-chuck-chuck-net/slaptain

An early, experimental, one-person spare-time project.
